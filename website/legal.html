4. Nature of Activities & Fulfillment

Freerouting provides open-source Printed Circuit Board (PCB) routing algorithms, desktop software, and cloud API automation services.

  • Digital Software: The core Freerouting software is free, open-source software distributed under the GNU General Public License v3.0 (GPLv3).
