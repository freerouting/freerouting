About Freerouting - The PCB Auto-Routing Standard

Freerouting is an open-source, fully automated PCB routing software engine designed for hardware engineers, PCB designers, makers, and students. By taking the mathematical complexity out of routing printed circuit boards, Freerouting turns days of tedious manual trace placement into minutes of automated optimization, saving time and delivering clean, violation-free PCB layouts.

Modern Graphical User Interface & Interactive Routing

Universal EDA Compatibility & Supported Formats

Freerouting integrates seamlessly with virtually all major Electronic Design Automation (EDA) suites and industry-standard exchange formats:

  • KiCad Integration: Full bidirectional workflow via KiCad's Specctra export/import and dedicated community KiCad plugins.
  • Autodesk EAGLE: Native ULP exporter integration for one-click routing and automatic back-annotation.
  • EasyEDA: Direct support for automated trace generation via Specctra DSN export.
  • Target 3001!, tscircuit & pcb-rnd: Automated routing pipelines across modern open-source and professional EDA platforms.
  • Specctra DSN & SES Format: Full compliance with industry-standard .dsn design files and .ses routing session output.

Key Features & Core Routing Capabilities

  • Multi-Threaded Optimization Engine: Freerouting leverages parallel CPU workers to run multiple rip-up and re-route passes simultaneously, finding optimal shortest paths and minimal via counts.
  • Flexible Configuration Pipeline: Configure routing rules and clearances via JSON config files, environment variables, command-line arguments, or the interactive GUI.
  • Headless CLI & Batch Automation: Integrate Freerouting directly into CI/CD pipelines, automated hardware testing, and build scripts with full command-line support.
  • Model Context Protocol (MCP) Server: Connect AI agents (Cursor, Claude Desktop, Cline, Roo Cline) to execute PCB routing jobs as native tool calls.
  • REST API: Deploy headless Freerouting instances in the cloud or on local servers for scalable automated routing services.
  • Cross-Platform & Containerized: Native support for Windows, Linux, and macOS, alongside official multi-architecture Docker containers (x64 and ARM64).
  • Global Localization: Professional localized user interfaces in 26 languages.

MCP Server for AI Coding Assistants

Freerouting includes a native Model Context Protocol (MCP) server that empowers LLM-based coding assistants to manage PCB routing directly from your editor or chat. Instead of manual clicking, an agent can initiate sessions, upload .dsn design files, configure constraints, run multi-pass autorouting, and return the finished .ses session file.

Flexible Setup:

  • Cloud Public API: Use a Freerouting API key (request access here) and connect your assistant via npx @freerouting/freerouting-mcp-server.
  • Local / Offline: Run the Freerouting executable on your local machine with MCP enabled to keep all proprietary hardware design files on your system.
