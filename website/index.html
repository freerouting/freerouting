About Freerouting

The Industry Standard in Automated PCB Routing

By taking the mathematical complexity out of routing printed circuit boards, Freerouting turns days of tedious manual trace placement into minutes of automated optimization, delivering clean, violation-free PCB layouts.

Core Capabilities

Engineered for Algorithmic Performance

Built from the ground up for high-speed rip-up, topological pathfinding, and clean clearance enforcement.

Flexible Configuration Pipeline

Configure routing rules, clearances, and layer costs via JSON config files, environment variables, command-line arguments, or the interactive GUI.

Headless CLI & Batch Automation

Integrate Freerouting directly into CI/CD pipelines, automated hardware testing, and build scripts with comprehensive command-line support.

Model Context Protocol (MCP)

Connect AI coding assistants (Cursor, Claude Desktop, Cline, Roo Cline) to execute PCB routing jobs directly as native tool calls.

REST API & Server Architecture

Deploy headless Freerouting instances in the cloud or on local servers for scalable automated routing services and web-based EDA integrations.

Cross-Platform & Containerized

Native support for Windows, Linux, and macOS, alongside official multi-architecture Docker containers (x64 and ARM64).

Localized in 36 World Languages

Professional localized user interfaces and documentation across 36 languages for hardware engineers worldwide.

AI Integration

MCP Server for AI Coding Assistants

Freerouting includes a native Model Context Protocol (MCP) server that empowers LLM-based coding assistants to manage PCB routing directly from your editor or chat. Instead of manual clicking, an agent can initiate sessions, upload .dsn design files, configure constraints, run multi-pass autorouting, and return the finished .ses session file.

Terminal • npx
npx @freerouting/freerouting-mcp-server

Cloud Public API

Use a Freerouting API key (request access here) and connect your assistant via npx @freerouting/freerouting-mcp-server.

Local / Offline Mode

Run the Freerouting executable on your local workstation with MCP enabled to keep all proprietary hardware design files strictly on your system.
